# Twinbooks email signature

Signature HTML légère aux couleurs actuelles de Twinbooks.

## Installation

1. Ouvrir `preview.html` dans un navigateur.
2. Sélectionner uniquement la signature, à partir du logo jusqu'à la baseline.
3. Copier, puis coller dans les paramètres de signature de Gmail, Outlook ou Apple Mail.

Dans Gmail ou Apple Mail, si le logo n'est pas conservé lors du collage, importer `LogoTwinbooksMark.png` dans l'éditeur de signature. Le fichier est déjà transparent et dimensionné à 48 × 48 px pour éviter qu'Apple Mail ne l'agrandisse.

Le fichier `signature.html` contient uniquement le bloc final à copier ou intégrer ; `preview.html` sert à contrôler son rendu.
